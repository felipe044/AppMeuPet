| Linha                    | O que faz?                                        |
| ------------------------ | ------------------------------------------------- |
| `collection(db, "pets")` | Aponta para a coleção onde vamos salvar           

| `addDoc(...)`            | Cria um documento novo com ID automático          |

| `async/await`            | Espera o Firebase salvar antes de continuar       |

| `try/catch`              | Trata erros de rede ou permissões                 |

| `return docRef.id`       | Devolve o ID para a tela, se precisar usar depois |
